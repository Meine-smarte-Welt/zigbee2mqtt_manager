# Zigbee2MQTT Manager за Home Assistant

📖 **Детаљан водич са позадином (на немачком):** [Zigbee2MQTT Manager за Home Assistant на meinesmartewelt.de](https://meinesmartewelt.de/zigbee2mqtt-manager-home-assistant/)

> **Напомена о преводу:** Ово је скраћена верзија на српском (ћирилица). Пун опис свих функција налази се у [немачкој верзији](README.md) и [енглеској верзији](README.en.md). Ћирилични превод је припремљен без провере изворног говорника – исправке су добродошле као Issue на GitHub-у.

Zigbee2MQTT Manager омогућава управљање Zigbee2MQTT-ом директно у Home Assistant-у: уређаји, батерије, ажурирања фирмвера, групе, повезивања (bindings) и мост (bridge) у једној картици на контролној табли – као HACS интеграција.

![Листа уређаја у картици](docs/images/zigbee2mqtt_manager_karte.webp)

## Шта је ново у 1.2.1

- **Мрежа из главног приказа:** у листи уређаја и под **Bridge → Стање** налази се дугме **Мрежа** које отвара мрежну мапу Zigbee2MQTT-а. Адреса се узима из кључа картице `network_url`, опције интеграције **Адреса мапе мреже**, подешавања Z2M `frontend.url` (уз додатак `/#/network`) или апликације Zigbee2MQTT у бочној траци. *Непроверено:* да ли путања `/#/network` важи за сваку верзију Z2M-а – у супротном унеси `network_url`.
- **Везе ка ентитету и уређају:** у прозору уређаја додир на име ентитета отвара његов дијалог у Home Assistant-у (икона за копирање остаје). Дугме **Отвори уређај** води на страницу уређаја у Home Assistant-у.
- **Назив у бочној траци:** у **Конфигуриши** можеш поставити **назив у бочној траци** (подразумевано „Zigbee2MQTT Manager“, највише 40 знакова), тако да се панел разликује од апликације Zigbee2MQTT.
- **Уређаји који недостају:** интеграција памти сваки уређај који је Zigbee2MQTT икада пријавио. Ако нестане са Z2M листе, остаје **сиво** са ознаком **недостаје** (чип, филтер, сензор **Уређаји који недостају**, догађај `zigbee2mqtt_manager_device_missing`, Notification Center). Када се уређај врати, ознака нестаје сама. **Заборави** га трајно уклања из меморије (само администратори).
- **innr утичнице без слике (исправљено):** код модела са размаком у називу (нпр. `SP 120`) слика је недостајала јер је картица другачије градила адресу него Z2M фронтенд. *Непроверено* на погођеним утичницама.
- **Base topic:** опција сада у опису приказује коришћени base topic. Узрок промене на подразумевани topic после ажурирања није нађен у коду; интеграција сама не мења base topic.

## Инсталација

1. HACS → три тачке → **Прилагођени репозиторијуми** → `https://github.com/Meine-smarte-Welt/zigbee2mqtt_manager` → категорија **Интеграција**.
2. Инсталирај, поново покрени Home Assistant.
3. **Подешавања → Уређаји и услуге → Додај интеграцију → Zigbee2MQTT Manager.** Потребан је Home Assistant 2025.6 или новији, MQTT интеграција и Zigbee2MQTT 2.x.
4. Додај картицу `custom:zigbee2mqtt-manager-card` на контролну таблу и очисти кеш прегледача (Ctrl+F5).
